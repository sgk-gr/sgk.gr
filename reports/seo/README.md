# Μηνιαίο αρχείο SEO & Traffic

Ένας φάκελος ανά μήνα: `YYYY-MM/` με `README.md` (ανάλυση) και `raw/` (CSV από Search Console & GA4).

## Κάθε μήνα
1. Εξαγωγή Search Console (Τελευταίες 28 ημέρες) → CSV.
2. Εξαγωγή GA4 «Σύνοψη αναφορών» → CSV.
3. Τα αρχεία μπαίνουν στον φάκελο `reports/seo/<μήνας>/raw/` (όχι στο `public/`, γιατί το `public/` είναι προσβάσιμο από το internet).
4. Ο βοηθός γράφει το `README.md` του μήνα και τη σύγκριση με τον προηγούμενο.
