# SmartTech E-shop LiveAvatar Demo

Ένα πιλοτικό e-shop με 10 προϊόντα και ενσωματωμένο **Live Customer Support** με 3D Avatar, το οποίο χρησιμοποιεί το **Google Gemini API** για να απαντάει στα ελληνικά!

## Οδηγίες Εκτέλεσης

1. Ανοίξτε το τερματικό σας.
2. Τρέξτε την παρακάτω εντολή για να ξεκινήσετε τον τοπικό server:
   ```bash
   python server.py
   ```
3. Ανοίξτε το πρόγραμμα περιήγησής σας (Browser) στη διεύθυνση:
   [http://localhost:8000](http://localhost:8000)
4. Πατήστε το κουμπί **"Σύνδεση με AI Assistant"** για να φορτώσει το ζωντανό Avatar.
5. Μιλήστε του (ή γράψτε του) στα ελληνικά και ρωτήστε τον για τα προϊόντα του καταστήματος!
